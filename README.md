# Транспортная задача: метод северо-западного угла + метод потенциалов (МОДИ)

Программа с графическим интерфейсом для решения классической транспортной задачи.  
Реализованы два этапа:
- построение начального опорного плана **методом северо-западного угла**;
- оптимизация плана **методом потенциалов (МОДИ)** с пошаговым отображением всех итераций.

Ввод данных возможен вручную через интерфейс или загрузкой из `.txt` файла.  
Работает на Windows, Linux и macOS.

**Примеры файлов '.txt':**

'test1.txt' - 3 поставщика, 3 потребителя

'test2.txt' - 2 поставщика, 4 потребителя

### Формат файла для загрузки

Файл должен содержать ровно **4 + m строк** (где `m` — число поставщиков):

1. **Первая строка:** два целых числа `m n` (количество поставщиков и потребителей через пробел).  
   Оба числа должны быть от 1 до 10.
2. **Следующие `m` строк:** матрица тарифов перевозок.  
   Каждая строка содержит ровно `n` целых чисел (стоимости перевозки от соответствующего поставщика ко всем потребителям).
3. **Одна строка с запасами:** ровно `m` целых чисел (запасы поставщиков).
4. **Последняя строка с потребностями:** ровно `n` целых чисел (потребности потребителей).

Все числа разделяются пробелами или переносами строк. Пустые строки игнорируются.
